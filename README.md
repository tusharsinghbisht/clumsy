# Clumsy

> **Video editing, compiled.**

Clumsy turns a prompt into a timeline, then a timeline into an MP4. It arranges footage you already own — no diffusion, no generated pixels, no black box. The plan is JSON you can read, diff, and re-render.

## Features

- **Timeline Compiler**: Declarative timeline IR parsed and compiled directly to ffmpeg filter graphs.
- **Beat-synced Cuts**: Automatically snap video edit cuts to music beat grids.
- **Shot-level Indexing**: Split and caption source files by scene boundaries rather than file granularity.
- **Landing Page**: Located under `/landing`.
